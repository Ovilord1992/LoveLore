# Amoria — AI Prompts для создания контента

## 📖 Промпт для написания сценария новеллы

```
Ты — профессиональный сценарист интерактивных визуальных новелл в жанре романтики.
Целевая аудитория: девушки и женщины 16-35 лет.

Напиши сценарий новеллы для движка Amoria. Формат — JSON.

### Требования к сюжету:
- Главная героиня — от первого лица, без имени (игрок ассоциирует себя с ней)
- 2-3 романтических интереса (мужские персонажи) с разными архетипами (напр. холодный аристократ, тёплый друг детства, загадочный незнакомец)
- У каждого персонажа — своя ветка отношений (route)
- Выборы игрока влияют на отношения: любовь (love), доверие (trust), страсть (passion)
- Минимум 3 главы по 5-8 сцен
- Каждая сцена содержит: диалоги, нарратив от лица героини, 1-2 выбора
- Включи 2-3 премиум-выбора за 💎 алмазы (15-30 шт) — это особенные моменты (поцелуй, откровенный разговор, эксклюзивная CG-сцена)
- Тон: эмоциональный, атмосферный, с лёгкой интригой

### Формат JSON для каждой главы:
{
  "id": "chapter_1",
  "title": "Название главы",
  "number": 1,
  "firstSceneId": "ch1_s1",
  "scenes": [
    {
      "id": "ch1_s1",
      "background": "описание_фона.png",
      "music": "настроение_музыки.mp3",
      "charactersOnScreen": [
        { "characterId": "id", "spriteId": "эмоция", "position": "left|center|right", "animation": "fade_in" }
      ],
      "events": [
        { "type": "narration", "text": "Мысли героини..." },
        { "type": "dialogue", "speaker": "id_персонажа", "text": "Реплика" },
        {
          "type": "choice",
          "choices": [
            {
              "text": "Вариант ответа",
              "effects": { "имя_love": "+2" },
              "nextSceneId": "ch1_s2"
            },
            {
              "text": "💎 Премиум вариант",
              "premium": true,
              "cost": 15,
              "effects": { "имя_love": "+5", "unlocked_cg": "название_cg" },
              "nextSceneId": "ch1_s2_special"
            }
          ]
        }
      ],
      "nextSceneId": "ch1_s2"
    }
  ]
}

### Также создай:
1. meta.json — { id, title, description (2-3 предложения, интригующие), author, coverImage: null, tags: [...], totalChapters: N }
2. characters.json — { characters: [{ id, name, color (HEX), sprites: [{ id: "эмоция", image: "файл.png" }] }] }
3. variables.json — начальные переменные отношений и флаги (все = 0 или false)

### Список эмоций для спрайтов:
neutral, smile, sad, angry, surprised, shy, serious, flirty, thinking, crying, laughing

### Список позиций персонажей:
left, center, right

### Сеттинг новеллы: [ОПИШИ СЕТТИНГ — напр. "Современный Токио, университет искусств" или "Викторианская Англия, поместье герцога"]
```

## 🎨 Промпт для генерации фонов (backgrounds)

```
Создай фоновое изображение для визуальной новеллы в жанре романтики.

Стиль: аниме/манга, мягкие цвета, атмосферное освещение, высокая детализация.
Пропорции: 16:9, горизонтальная ориентация (1920x1080).
БЕЗ персонажей и людей — только окружение.
Настроение: [романтичное / таинственное / тёплое / драматичное / меланхоличное]

Сцена: [ОПИСАНИЕ — напр. "Ночной Петербург, набережная Невы, фонари отражаются в воде, лёгкий туман, видна Петропавловская крепость вдали"]

Важно: изображение должно быть пригодно как фон — основное пространство свободно для размещения персонажей и диалоговых окон в нижней части экрана.
```

| Особняк | Роскошный зал старинного особняка, хрустальная люстра, мраморный пол, высокие окна с бархатными шторами |
| Пляж | Тропический пляж на закате, оранжево-розовое небо, спокойное море, пальмы, следы на песке |
| Класс | Японский школьный класс после уроков, закатный свет через окна, пустые парты, доска |
| Бальный зал | Великолепный бальный зал XVIII века, свечи, позолота, паркет, огромные зеркала |
| Спальня | Элегантная спальня с балконом, лунный свет, шёлковые шторы, вид на ночной город |

## 🎭 Промпт для генерации спрайтов персонажей

```
Создай спрайт персонажа для визуальной новеллы.

Стиль: аниме, полу-реалистичный, красивая прорисовка лица и волос.
Формат: персонаж по пояс или по грудь, фронтальный ракурс, ПРОЗРАЧНЫЙ ФОН (PNG).
Размер: примерно 800x1200 пикселей.

Персонаж: [ИМЯ]
Пол: [мужской / женский]
Возраст: [18-25 / 25-35]
Внешность: [ОПИСАНИЕ — напр. "Высокий, тёмные волосы до плеч, серо-голубые глаза, лёгкая щетина, острые скулы"]
Одежда: [ОПИСАНИЕ — напр. "Чёрное пальто поверх белой рубашки, серебряные часы"]
Эмоция: [neutral / smile / sad / angry / surprised / shy / serious / flirty / thinking / crying / laughing]

ВАЖНО:
- Один и тот же персонаж должен выглядеть идентично на всех спрайтах — меняется ТОЛЬКО выражение лица
- Прозрачный фон обязателен
- Персонаж должен смотреть слегка в сторону зрителя
- Стиль должен быть консистентным для всех персонажей одной новеллы
```

### Совет по консистентности:
Генерируй все эмоции одного персонажа в одной сессии, используя первое изображение как reference. Промпт для дополнительных эмоций:

```
Используя [прикреплённое изображение] как reference, создай тот же персонаж с эмоцией: [shy].
Сохрани идентичную одежду, причёску, цвет глаз. Измени ТОЛЬКО выражение лица.
Прозрачный фон (PNG).
```

## 🖼️ Промпт для CG-артов (галерея)

```
Создай CG-арт (полноэкранную иллюстрацию) для визуальной новеллы.

Стиль: аниме, высокая детализация, кинематографичная композиция, эмоциональное освещение.
Пропорции: 9:16, вертикальная ориентация (1080x1920) — для мобильного экрана.

Сцена: [ОПИСАНИЕ МОМЕНТА — напр. "Он нежно берёт её руку под звёздным небом на крыше, ветер развевает волосы, город сияет внизу"]

Персонажи:
- Она: [описание внешности героини]
- Он: [описание внешности персонажа]

Настроение: [романтичное / напряжённое / нежное / драматичное]
Освещение: [лунный свет / закат / свечи / неон]

ВАЖНО: это ключевой момент истории, иллюстрация должна быть эмоционально насыщенной и запоминающейся.
```

```
Настроение: [ОПИСАНИЕ — напр. "Нежная меланхолия, ощущение ностальгии по ушедшей любви, с нарастающей надеждой к концу"]

БЕЗ вокала, только инструментальная.
```

## 📋 Чеклист создания новеллы

1. **Сценарий** → используй промпт для истории, получи JSON
2. **Фоны** → для каждой уникальной локации сгенерируй фон (16:9, без людей)
3. **Спрайты** → для каждого персонажа сгенерируй 4-6 эмоций (прозрачный фон)
4. **CG-арты** → 2-3 на главу для премиум-моментов (9:16)
5. **Музыка** → 3-5 треков на разные настроения
6. **Сборка** → упакуй в ZIP, загрузи через админку
