# Amoria Editor

Визуальный веб-редактор для создания интерактивных новелл для платформы Amoria. Позволяет авторам создавать сценарии с ветвлениями, загружать изображения и экспортировать готовые паки — не написав ни строчки кода.

## Стек

- **React 19 + TypeScript** — UI
- **Vite** — сборка и dev-сервер
- **Zustand** — управление состоянием проекта и загруженными изображениями
- **@xyflow/react** — визуальный граф сцен (drag & drop)
- **JSZip + FileSaver** — экспорт/импорт ZIP-паков с изображениями
- **Lucide React** — иконки

---

## Быстрый старт

```bash
npm install
npm run dev                    # http://localhost:5173
```

Редактор работает полностью автономно (не требует сервера для создания новелл).

## Функциональность

### Визуальный граф сцен

- Каждая сцена — узел на канве (@xyflow/react)
- Связи между сценами — стрелки (nextSceneId из выборов)
- Drag & drop для расположения сцен
- Визуальное представление ветвлений сценария
- Цветовая маркировка: обычные выборы (розовый), премиум (фиолетовый)

### Изображения

Все изображения хранятся в памяти (Zustand store) и включаются в ZIP при экспорте.

| Тип | Путь в ZIP | Как загрузить |
|-----|------------|---------------|
| **Обложка** | `cg/cover.png` | Мета → клик по области обложки |
| **Фоны** | `backgrounds/{name}.png` | Настройки сцены → кнопка 📷 / Событие «Смена фона» → кнопка 📷 |
| **Спрайты** | `sprites/{charId}/{charId}_{spriteId}.ext` | Персонажи → развернуть → клик по миниатюре спрайта |

В превью отображаются реальные загруженные изображения (фоны и спрайты). Если изображение не загружено — показывается градиент/плейсхолдер.

### Редактор событий

Для каждой сцены можно добавлять события:

| Тип события | Описание | Поля |
|-------------|----------|------|
| `dialogue` | Реплика персонажа | speaker (выпадающий список), text |
| `narration` | Описание, мысли | text |
| `choice` | Выбор игрока | варианты: text, nextSceneId, effects, premium, cost |
| `changeBackground` | Смена фона | background (имя файла) + загрузка изображения |
| `changeSprite` | Смена спрайта | characterId + spriteId (выпадающие списки) |
| `set_variable` | Изменение переменной | variable, value |
| `play_sound` | Воспроизведение звука | sound |

Все события можно перемещать вверх/вниз, удалять и редактировать inline.

### Персонажи

- **ID, имя, цвет** — основные свойства
- **Спрайты** — раскрываемый список с миниатюрами:
  - Добавление/удаление спрайтов
  - Загрузка изображения для каждого спрайта (клик по миниатюре)
  - ID и метка (label) для каждого спрайта
  - Путь автоматически формируется: `sprites/{charId}/{charId}_{spriteId}.ext`

### Персонажи на сцене

Каждая сцена имеет список `charactersOnScreen`:

- Добавление персонажа через выпадающий список (только не добавленные)
- Выбор спрайта (из спрайтов персонажа)
- Позиция: лево / центр / право
- Удаление с кнопкой
- Отображение в превью с реальными спрайтами

### Управление контентом

- **Метаданные**: ID, название, автор, описание, теги, обложка
- **Главы**: добавление/удаление, список сцен внутри главы
- **Переменные**: начальные значения (отношения, флаги), add/edit/delete

### Превью

- Мобильный фрейм справа (280×560px) — как на телефоне
- **Реальные загруженные фоны** вместо градиентов
- **Реальные спрайты** персонажей вместо заглушек с буквой
- Диалоги, нарратив, выборы (с 💎 для премиум)
- Точечная навигация по событиям (активное выделено)
- Отображение событий changeBackground и changeSprite

### Валидация

- BFS-обход графа сцен: проверка достижимости всех сцен
- Обнаружение битых ссылок (nextSceneId → несуществующая сцена)
- Проверка на пустые тексты
- Несуществующие персонажи (speaker, charactersOnScreen)
- Выборы без вариантов

### Экспорт / Импорт

#### Экспорт ZIP

Готовый пакет для загрузки на сервер Amoria. Включает все загруженные изображения:

```
my_novel.zip
├── meta.json                          # Метаданные
├── characters.json                    # Персонажи со спрайтами
├── variables.json                     # Начальные переменные
├── chapters/
│   ├── chapter_1.json                 # Глава 1 (сцены, события)
│   └── chapter_2.json
├── backgrounds/                       # Фоновые изображения
│   ├── city_night.png
│   └── cafe.png
├── sprites/                           # Спрайты персонажей
│   ├── alex/
│   │   ├── alex_neutral.png
│   │   └── alex_smile.png
│   └── maria/
│       └── maria_neutral.png
└── cg/
    └── cover.png                      # Обложка
```

> **Важно:** `meta.json` в корне ZIP (не во вложенной папке). Это требование сервера Amoria.

#### Экспорт JSON

Весь проект одним JSON-файлом (без изображений). Подходит для резервных копий.

#### Импорт JSON

Загрузка ранее сохранённого `.json` проекта.

#### Импорт ZIP

Загрузка ранее экспортированного `.zip` пакета:

- Извлекает meta, characters, variables, chapters
- Загружает все изображения из `backgrounds/`, `sprites/`, `cg/`
- Поддерживает ZIP с файлами в корне или в подпапке
- После импорта — все изображения доступны в превью

## Формат данных

Редактор генерирует JSON в формате, полностью совместимом с движком Amoria (Flutter-приложение). Типы определены в `src/types/novel.ts` и совпадают с Dart-моделями в `lib/models/`.

### Ключевые типы

```typescript
interface NovelProject {
  meta: NovelMeta;           // id, title, description, author, tags, coverImage
  characters: Character[];    // Персонажи со спрайтами
  chapters: Chapter[];        // Главы со сценами
  variables: Record<string, any>; // Начальные переменные
}

interface Character {
  id: string;
  name: string;
  color: string;               // HEX цвет для UI
  sprites: CharacterSprite[];  // { id, image, label }
}

interface Scene {
  id: string;
  background?: string;          // Имя файла фона (city_night.png)
  music?: string;
  charactersOnScreen: SceneCharacter[];  // { characterId, spriteId, position }
  events: SceneEvent[];
  nextSceneId?: string;         // Автопереход к следующей сцене
}

interface SceneEvent {
  type: EventType;              // dialogue | narration | choice | changeBackground | changeSprite | ...
  speaker?: string;             // ID персонажа (для dialogue)
  text?: string;
  choices?: Choice[];           // Для choice
  background?: string;          // Для changeBackground
  characterId?: string;         // Для changeSprite
  spriteId?: string;            // Для changeSprite
}

interface Choice {
  text: string;
  nextSceneId: string;
  effects?: Record<string, string>;  // { "alex_love": "+3" }
  condition?: Condition;
  premium?: boolean;
  cost?: number;                     // Стоимость в алмазах
}
```

## Руководство для писателей

Пошаговая инструкция по созданию новеллы — от пустого проекта до готового пака.

### Шаг 1. Создание проекта

1. Открой редактор: `http://localhost:5173`
2. Перейди на вкладку **⚙ Мета** (левая панель)
3. Заполни поля:
   - **ID новеллы** — уникальный идентификатор (латиницей, без пробелов, например `venetian_whispers`)
   - **Название** — заголовок новеллы (на любом языке)
   - **Автор** — твоё имя
   - **Описание** — краткий синопсис для каталога
   - **Теги** — через запятую (`романтика, мистика, Венеция`)
4. Кликни по области **Обложка** → выбери изображение (попадёт в `cg/cover.png`)

### Шаг 2. Персонажи

1. Перейди на вкладку **👥 Персонажи**
2. Нажми **＋** → появится карточка «Новый персонаж»
3. Заполни:
   - **Цвет** — цвет имени в диалогах (клик по кружку)
   - **Имя** — как отображается в игре (`Александр`, `Мария`)
   - **ID** — внутренний идентификатор (`alex`, `maria`)
4. Нажми **▼** чтобы развернуть **спрайты**:
   - У каждого персонажа уже есть спрайт `neutral`
   - Кликни по серой миниатюре → загрузи изображение спрайта
   - Нажми **＋** для добавления новых спрайтов (`smile`, `angry`, `sad`)
   - Заполни **ID** и **Название** для каждого спрайта

> 💡 Один персонаж = несколько спрайтов (эмоций). В игре можно менять спрайт событием `changeSprite`.

### Шаг 3. Переменные

1. Перейди на вкладку **# Переменные**
2. Введи имя переменной → **＋**
3. Типичные переменные:
   - `alex_love` = `0` — отношения с Александром
   - `maria_love` = `0` — отношения с Марией
   - `has_key` = `false` — флаг (есть ли ключ)
   - `chapter_1_choice` = `0` — запоминание выбора

> Переменные меняются через `effects` в выборах: `{ "alex_love": "+3" }`.

### Шаг 4. Структура глав и сцен

1. Перейди на вкладку **📖 Главы**
2. Глава 1 уже создана. Нажми **＋** для добавления новых глав.
3. Кликни по главе → откроется список сцен
4. Нажми **＋ Сцена** для добавления сцен

**Как именовать сцены:**
- `ch1_s1` — глава 1, сцена 1 (начало)
- `ch1_s2_park` — сцена в парке
- `ch1_s3_choice_a` — ветка A после выбора
- `ch1_s3_choice_b` — ветка B после выбора
- `ch1_ending` — концовка главы

> 💡 Кликни на сцену в списке слева **или** на узел графа в центре — откроется редактор событий.

### Шаг 5. Настройка сцены

Выбери сцену → в центральной панели появятся настройки:

1. **Фон** — имя файла (`venice_canal.png`). Нажми 📷 для загрузки изображения.
2. **Музыка** — имя файла (`romantic_theme.mp3`)
3. **Следующая сцена** — ID сцены для автоперехода (если нет выборов)
4. **Персонажи на сцене** — выбери из выпадающего списка:
   - Спрайт (какая эмоция)
   - Позиция: лево / центр / право

### Шаг 6. Наполнение событиями

Внизу редактора — кнопки добавления событий. Игрок увидит их по порядку сверху вниз:

#### 💬 Диалог
Персонаж говорит:
- **Говорящий** — выбери из списка персонажей
- **Текст** — реплика

#### 📖 Нарратив
Описание, мысли героини, атмосфера:
- **Текст** — курсивный текст без имени

#### 🖼 Смена фона
Меняет фоновое изображение посреди сцены:
- **Имя фона** — файл (`night_city.png`)
- 📷 — загрузить новое изображение

#### 🎭 Смена спрайта
Меняет эмоцию персонажа:
- **Персонаж** — кто меняет выражение
- **Спрайт** — на какой (smile, angry, sad...)

#### 🔀 Выбор (ветвление!)
Это ключевой элемент — здесь сюжет разветвляется:

```
Пример: Вечер в кафе. Марко приглашает на прогулку.

Вариант 1: "Согласиться"      → ch1_s4_walk     effects: { marco_love: "+2" }
Вариант 2: "Отказаться"       → ch1_s4_alone     effects: { marco_love: "-1" }
Вариант 3: "💎 Пошутить"      → ch1_s4_joke      effects: { marco_love: "+5" }  premium, cost: 15
```

Для каждого варианта заполни:
- **Текст** — что видит игрок
- **→ ID сцены** — куда ведёт выбор (ID существующей сцены!)
- **💎** — премиум-выбор (чекбокс) → появится поле стоимости в алмазах

### Шаг 7. Ветвление сюжета

Ветвление в Amoria строится на двух механизмах:

#### Механизм 1: Выборы → разные сцены

Самый простой способ. Каждый вариант в событии «Выбор» указывает на свою сцену:

```
Сцена: ch1_s3_decision
  └─ Выбор:
       ├─ "Пойти в парк"     → ch1_s4_park
       └─ "Остаться дома"    → ch1_s4_home

Сцена: ch1_s4_park
  └─ (события парка...)
  └─ Следующая сцена: ch1_s5_evening

Сцена: ch1_s4_home
  └─ (события дома...)
  └─ Следующая сцена: ch1_s5_evening   ← обе ветки сходятся
```

На графе это выглядит как развилка: из одного узла идут две стрелки, которые потом могут сойтись обратно.

#### Механизм 2: Следующая сцена (линейный поток)

Поле «Следующая сцена (ID)» в настройках сцены — это автопереход. Игрок не видит выбора, просто продолжает читать. Используй для:
- Линейной цепочки сцен без выборов
- Объединения веток обратно в одну линию

```
ch1_s1 ──→ ch1_s2 ──→ ch1_s3 ──→ ...
   (через поле «Следующая сцена»)
```

#### Паттерн: Развилка и схождение

Типичная структура главы:

```
          ch1_s1 (начало)
              │
          ch1_s2 (выбор)
         ╱          ╲
   ch1_s3_a      ch1_s3_b      ← разные ветки
         ╲          ╱
          ch1_s4 (общее)        ← схождение
              │
          ch1_s5 (выбор)
         ╱    │     ╲
      ...    ...    ...         ← больше веток
```

#### Паттерн: Условные выборы

Варианты могут быть доступны **только при выполнении условия** (задаётся в JSON):

```json
{
  "text": "Признаться в чувствах",
  "condition": { "variable": "alex_love", "operator": ">=", "value": 5 },
  "nextSceneId": "ch1_confession"
}
```

Если `alex_love < 5` — этот вариант не покажется. Операторы: `>=`, `<=`, `==`, `!=`, `>`, `<`.

> ⚠️ Условия пока задаются только через JSON-экспорт/импорт. В визуальном редакторе — в будущих версиях.

#### Паттерн: Премиум-выборы

Вариант с 💎 стоит алмазы и обычно даёт лучший результат:

```
Вариант 1: "Просто поздороваться"    → ch1_s3     effects: { alex_love: "+1" }
Вариант 2: "💎 Обнять (15 💎)"       → ch1_s3_hug  effects: { alex_love: "+5" }  premium
```

### Шаг 8. Граф сцен

В центральной панели видно **визуальный граф** — все сцены и связи между ними:

- **Серые стрелки** (анимированные) — «Следующая сцена» (автопереход)
- **Розовые стрелки** — обычные выборы
- **Фиолетовые стрелки** — премиум-выборы
- **Надписи на стрелках** — текст варианта (первые 20 символов)

Перетаскивай узлы для удобного расположения. Кликни на узел — откроется редактор сцены.

> 💡 Если видишь «висящий» узел без входящих стрелок — его нельзя достичь в игре. Валидация предупредит об этом.

### Шаг 9. Превью

В правой панели — мобильный превью (280×560px):

- Показывает **реальный загруженный фон** (или градиент, если не загружен)
- Показывает **спрайты персонажей** на своих позициях
- Отображает текущее событие (диалог / нарратив / выборы)
- Точки внизу — навигация по событиям сцены

Кликни на событие в списке — превью обновится.

### Шаг 10. Валидация

Перед экспортом перейди на вкладку **⚠ Валидация** → нажми «Проверить сценарий»:

| Проверка | Тип |
|----------|-----|
| ID новеллы не задан | ❌ Ошибка |
| Название не указано | ❌ Ошибка |
| Начальная сцена не найдена | ❌ Ошибка |
| Выбор ведёт к несуществующей сцене | ❌ Ошибка |
| Персонаж не найден среди созданных | ❌ Ошибка |
| Выбор без вариантов | ❌ Ошибка |
| Пустой текст диалога/нарратива | ⚠ Предупреждение |
| Сцена недостижима из начальной | ⚠ Предупреждение |
| Автор не указан | ⚠ Предупреждение |

### Шаг 11. Экспорт и публикация

1. Вернись на вкладку **⚙ Мета**
2. Нажми **📥 ZIP для Amoria** — скачается файл `{id}.zip`
3. ZIP включает все загруженные изображения и JSON-файлы
4. Загрузи на сервер:
   - Через админку: `http://localhost:5174` → Новеллы → Загрузить ZIP
   - Через API: `curl -X POST http://localhost:3000/v1/novels/upload -F "file=@my_novel.zip"`
5. Новелла появится в каталоге приложения

> 💡 Для резервной копии — нажми **📥 JSON** (без изображений, только структура).  
> 💡 Для продолжения работы — нажми **📤 Импорт** и выбери свой `.json` или `.zip` файл.

## Пример структуры простой новеллы

```
Глава 1: «Незнакомец»

│   ├── dialogue [alex]: "Простите, это место свободно?"
│   └── choice:
│       ├── "Да, конечно"       → ch1_s2  [alex_love +1]

├── ch1_s2 (кафе, разговор)
│   ├── changeSprite: alex → smile
│   ├── dialogue [alex]: "Спасибо. Я Александр."
│   ├── narration: "Он улыбнулся так, что стало теплее."

│       ├── "Рассказать о себе"     → ch1_s3_open   [alex_love +2]

│
├── ch1_s3_open (ветка: открытость)
│   ├── dialogue [alex]: "Как интересно!"
│   └── nextSceneId: ch1_s4

├── ch1_s3_quiet (ветка: молчание)
```
